# CodeAlpha_StockPortfolioTracker
Stock Portfolio Tracker
Project Description
The Stock Portfolio Tracker is a simple Python-based application that calculates the total investment value of stocks based on manually defined stock prices and user-entered quantities.
This project was developed as part of the CodeAlpha Python Internship.
Features

Displays available stock names.
Uses predefined stock prices.
Takes stock name and quantity as user input.
Calculates individual stock investment values.
Calculates the total investment value.
Saves the final result in a text file.

Technologies Used

Python
Dictionary
While Loop
Conditional Statements
User Input and Output
Basic Arithmetic
File Handling

How to Run

Install Python on your computer.
Download or clone this repository.
Open the project folder in VS Code.
Run the following command:

python task2_stock_tracker.py


Enter the stock name and quantity.
Type DONE to finish.
View the total investment value.

Sample Output
AAPL: 5 shares = $900
TSLA: 2 shares = $500

Total Investment Value: $1400
